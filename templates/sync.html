Google Sheets Setup Guide & Architecture

  1. Target Spreadsheet: Bound to {{ sync_status.spreadsheet_id }}.
  2. Google Apps Script: Handled by google_apps_script.js which enforces secret token verification.
  3. Durable Transactional Outbox: All user mutations commit to the database first, eliminating UI freezes. The background worker syncs pending items to Google Sheets via idempotent upserts.
  4. Change Data Capture (CDC): Every state change across Students, Semesters, Marks, Gaps, and Activities is tracked in sync_log with full payload snapshots.
